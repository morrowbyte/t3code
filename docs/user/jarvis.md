# Jarvis conversations in T3 Code

Keep T3 Code Desktop open in the same profile as Jarvis. Choose a default model
for the environment or its Scratch project before sending a Jarvis author task.
Each Jarvis conversation continues in its own ordinary Scratch thread. Further
turns join that conversation, and tasks can keep running while you talk to Jarvis.

Use Jarvis's results action as soon as you need to inspect progress, respond to a
question or decide an approval. It opens the existing conversation in a separate
T3 Code window, including while a task is running or waiting. Text, tools and
supported visuals appear there as they arrive. Approve or decline requests in
that conversation; Jarvis cannot approve its own requests.

These conversations require approvals. Jarvis's desktop actions still require
the Jarvis plan gate. Opening results or sending an author task does not approve
a desktop action.

If the connection drops, reconnect to check the original task before sending
anything again. An accepted submission means the task was recorded, and its
status may still be queued, running or waiting. An unavailable result or a gap
does not mean the task completed or failed; inspect its T3 conversation. When a
task is waiting, open results for the pending decision. Cancel targets the task
that Jarvis actually submitted; it does not redirect a newer task.
